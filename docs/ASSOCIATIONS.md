# What a bag brings to mind — selected development direction

Nicolás clarified the intended reading on 2026-10-13: opening a bag should reveal what CompAII knows that relates to it, where each item comes from, and briefly why it connects. The main result is a source-attributed inventory of associations. New elaboration is brief and optional, reserved for strong points that emerge. This refines the original reading roadmap before any remaining Nexus work. The v2 contract, reader and foreground source adapters implement this direction; the owning issues retain the real-bag delivery and acceptance evidence.

## Foreground traversal

1. Select the same immutable bag package/version the human sees. Read every selected item and its representation, including original media and attributed derivative coverage. Keep human input unchanged.
2. Use its subject, names and selected material to navigate relevant being-level HMK records, linked documents, maintained project sources and other selected bags. Follow discovered relationships into relevant sources; the bag's implementation repository is not the default limit of the topic. Use existing authorized recall and project retrieval rather than introducing another memory store.
3. Read the original evidence for each retained association, following all pages with the retained revision. Distinguish a memory of a conversation from its unavailable original transcript; preserve attribution, dates, corrections and uncertainty. Search rankings and top results are navigation, not the complete inventory.
4. Retain each inspected relevant item with a stable source identity/version, original title, type, date, author/provenance, locator or selected faithful excerpt, and a brief reason for its relationship to the bag. Direct references, remembered relationships and current interpretations must remain recognizable. Deduplicate repeated representations without erasing their origins.
5. State which sources/routes were searched, what was inspected, limits/truncation and unavailable evidence. Preserve the complete identified relevant inventory as reachable content; grouping and emphasis cannot silently hide the remaining items. The result represents what was recovered within this traversal, not a proof of all possible knowledge.
6. Add zero to three short observations only when strong points emerge. No required essay, generic synthesis, automatic project creation or automatic addition of discovered context to the bag's raw input.
