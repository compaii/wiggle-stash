# Portable continuity and chosen access

Wiggle Stash preserves selected ideas independently of model memory. Humans maintain it through conversation. The default local store is private; the project keeps executable recovery commands and this runbook, not live databases or private exports in Git.

## Full selected history

Ask for a recovery copy of named bags. The operator uses `archive --bag ID` (repeat for explicitly selected bags) `--output NEW.zip`. The private ZIP includes all their immutable revisions, correction and retirement history, operations/retry IDs, dated authored readings and evidence/relationship checkpoints, all delta checks, selected custody policy and every original/derivative object referenced by any revision. A manifest records exact file sizes and SHA-256. Local source-adapter paths are excluded: re-register current local copies after moving hosts.

`restore --archive FILE --destination NEW_DIRECTORY` validates the entire inventory, byte digests, database references, contiguous revision history, reading snapshots and delta integrity in a private staging directory before installing the new store. It refuses missing/corrupt/extra/traversal members and existing destinations. Retrieve a selected bag/revision or earlier reading from that independent store before choosing a switch. Keep the original store and archive as rollback; the restore command never overwrites them. No timer or backup scheduler is installed.

The archive is private, even when current bag inputs are public: earlier interpretations or chosen access policy may be restricted. Export creates no access grant. Never publish a full archive as public unless every retained original, reading and policy has actually been selected for that audience. Selected public reader editions keep their existing narrower content contract.

## Human-selected stewardship

`custody --recipient RESOLVED_ACTOR` (repeat) `--author HUMAN --source SELECTION` records the human's chosen Wiggle Stash readership and provenance. Resolve actors through `daimon-home targets`; acceptance of external grants belongs to that shared authority. New private bags default to the selected individuals, retaining the human/daimon collaborators. Public bags remain public. A later explicit narrower choice must be honored and discussed against the standing selection; it is not inferred from a display name, tribe membership or network access.

The selection covers Wiggle Stash bags and chosen recovery copies only. It grants no unrelated memory access, private-session import, credential custody or execution rights. Future-reader access is a present chosen grant; no proof of a future inheritance/legal process is claimed. New captures do not automatically update a published recovery copy: refresh it explicitly in the same foreground task when selected.

## Existing access authority

Use the installed daimon-home publisher, preserving resource identity/history and explicit visibility. Its shared Matrix resource registry supports public, paired human, VPN, selected individuals and selected tribes with independent enforcement. A receiving adapter that lacks an audience must refuse it, never broaden to complete publication. Every preview, original, range and dependency follows current and original audience checks. The public catalog omits private titles and bytes.

Qualification includes allowed/denied reads and revocation for every audience in the owning Cluster tests, plus a live selected-individual recovery copy: anonymous original/metadata reads are denied, an authorized current body retrieves exact selected bytes and restores all real bag versions/readings/checks independently. This does not claim that another human or being has opened the copy; they use their own existing authenticated access, without shared credentials.
